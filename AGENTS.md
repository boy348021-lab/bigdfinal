# Workspace Rules & Protected Modules

## 🚨 PROTECTED CODE SECTION – DO NOT MODIFY 🚨

The entire Leaderboard module is considered production-ready and locked.

This includes, but is not limited to:
- Lifetime Wager Leaderboard
- Monthly/15-Day Leaderboard
- Leaderboard UI and styling
- Leaderboard API integration
- Ranking logic
- Prize distribution display
- Progress bars
- Timers and countdowns
- Refresh/reset logic
- Filters, sorting, pagination
- Animations
- All leaderboard-related components, utilities, database queries, routes, and configuration.

Treat every leaderboard-related file, function, component, API, database query, and style as READ-ONLY.

DO NOT:
- Edit existing code.
- Refactor or optimize.
- Rename variables, functions, or files.
- Change styling or layout.
- Change API calls or database logic.
- Fix or "improve" anything in the leaderboard.
- Move code between files.
- Delete unused code.
- Format or reorganize protected files.

Only make changes to the files and features explicitly requested by the user. If a requested feature would require modifying the protected leaderboard code, STOP and ask for approval before making any changes.

Assume the leaderboard is fully tested and any unapproved modification is considered a breaking change.
